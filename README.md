# TripCanvas

A collaborative-feeling itinerary planner with a day rail, shared participant signal, friendly map, budget progress, and an editable plan timeline.

## Run locally

Open `index.html` in any modern browser. No dependencies are required.

## Try it

Choose a day in the itinerary rail or use **Add plan**. The project demonstrates a travel-product interface distinct from the other three projects, with a map-first desktop composition that becomes itinerary-first on mobile.
